## Principio Abierto-Cerrado en C# para Extender Código sin Modificarlo

- un componente debe ser abierto para extensiones y cerrado para cambios
- se deben utilizar tipos abstractos y multiples implementaciones para lograrlo
  (se apoya de case abstracta e interfaces)
- c# no soporta multiple-herencia
- c# soporta multiples implementaciones de interfaces
